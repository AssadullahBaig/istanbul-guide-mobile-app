# Istanbul Guide Mobile Application

AI-powered smart tourism mobile application for exploring historical landmarks in Istanbul using React Native, Expo, Supabase, offline caching, and AI-generated recommendations.

# Requirements

Install the following software before running the project:

* Node.js (LTS version)
* npm
* Git
* Expo Go mobile application
* Visual Studio Code (recommended)

Verify installation:

```bash
node -v
npm -v
git --version
```

---

# Clone the Repository

```bash
git clone https://github.com/AssadullahBaig/istanbul-guide-mobile-app.git
cd istanbul-guide-app-main
```

---

# 1. Setup Mobile Application

Navigate to the mobile app folder:

```bash
cd istanbul-guide-app
```

Install dependencies:

```bash
npm install
```

The Supabase configuration is already included inside:

```text
services/supabase.ts
```

---

# 2. Setup Places API

Open a new terminal.

Navigate to the Places API folder:

```bash
cd places-api
```

Install dependencies:

```bash
npm install
```

Start the Places API server:

```bash
node places-api.js
```

The Places API runs on:

```text
http://localhost:4000
```

---

# 3. Setup Tourism LLM API

Open another terminal.

Navigate to the Tourism LLM API folder:

```bash
cd tourism-llm-api
```

Install dependencies:

```bash
npm install
```

Create a `.env` file inside the `tourism-llm-api` folder.

Add the following:

```env
GOOGLE_API_KEY=your_google_gemini_api_key
GROQ_API_KEY=your_groq_api_key
OPENAI_API_KEY=your_openai_api_key
PORT=5000
```

Start the Tourism LLM API:

```bash
node server.js
```

The Tourism LLM API runs on:

```text
http://localhost:5000
```

---

# 4. Run the Mobile Application

Open another terminal.

Navigate to the mobile app folder:

```bash
cd istanbul-guide-app
```

Start Expo:

```bash
npx expo start
```

Expo will generate a QR code.

---

# 5. Run on Physical Mobile Device

Install **Expo Go** from the Google Play Store or Apple App Store.

Steps:

1. Open Expo Go
2. Scan the QR code generated by Expo
3. The application will launch on the phone

Requirements:

* Phone and computer must be connected to the same Wi-Fi network.

---

# Correct Startup Order

Start the services in this order:

| Terminal   | Folder               | Command              |
| ---------- | -------------------- | -------------------- |
| Terminal 1 | `places-api`         | `node places-api.js` |
| Terminal 2 | `tourism-llm-api`    | `node server.js`     |
| Terminal 3 | `istanbul-guide-app` | `npx expo start`     |

# Offline Support

The application supports offline fallback behavior using AsyncStorage caching.

If API requests fail or the device is offline:

1. Cached data is loaded
2. Cached AI descriptions are reused
3. Static fallback content is displayed if necessary

---

# AI Integration

The project integrates multiple AI providers through the Tourism LLM API:

* Gemini
* Pollinations
* Groq
* OpenAI

The backend uses a fallback chain to improve reliability and availability.
